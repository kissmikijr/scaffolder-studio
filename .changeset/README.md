# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you keep your versions across changelogs in sync. You can find the full documentation for it [in the repository](https://github.com/changesets/changesets)

We have a quick, helpful guide for you to get your mind around the whole concept. But as a summary:

- Add a changeset by running `yarn changeset`
- `yarn changeset:version` updates version and changelog
- `yarn changeset:publish` publishes packages

More on how to do this below.

## Getting Started

### Adding a changeset

When you want to start making changes to the codebase, you should make a branch from `main`, add a changeset and commit it with your changes.

```bash
yarn changeset
```

It will ask you what kind of change this is (major, minor, patch), which packages this affects, and will write a summary of what you're changing.

### Publishing

When you're ready to release packages:

1. Make sure you're on `main` and pulled the latest changes
2. Run `yarn changeset:version` to update versions and changelogs
3. Run `yarn changeset:publish` to publish to npm

Or use the GitHub Actions workflow which will do this automatically when you merge changesets to main.
